# Senova for Windows

Downloads and updates for the Senova desktop app, made by Senova Systems LLC. This repository holds
releases only; it has no source code.

**[Download the latest version](https://github.com/Senova-Systems-LLC/senova-desktop/releases/latest)**,
or visit [senovasys.com/senova/download](https://senovasys.com/senova/download).

- Windows 10 or 11, 64-bit (x64). Per-user install, no admin rights needed.
- Senova's models run on your PC. Setup downloads the engine and one model (Prelude 1, about 12 GB).
- Early builds are not code-signed yet, so Windows SmartScreen may warn you. Choose "More info", then "Run anyway".

By installing Senova you agree to the [terms of use](TERMS.md). The [privacy notice](PRIVACY.md) explains
what stays on your PC and when the app goes online. Open-source parts are listed in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
